# Servis-bilgi-katalogu

Bu proje, `public/` klasörüne koyduğunuz site dosyalarını tarayıcı üzerinden Basic Auth ile koruyarak yayınlar.

## Kullanım

```bash
npm start
```

Sunucu varsayılan olarak `http://localhost:3000` adresinde çalışır.

### Giriş bilgileri

- Kullanıcı adı: `admin`
- Şifre: `43214321`

Site dosyalarınızı proje içindeki `public/` klasörüne yükleyebilirsiniz.
